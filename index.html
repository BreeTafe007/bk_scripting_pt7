Welcome to Task Manager

Gelos Enterprises Task Manager is a responsive one page web application designed to help Gelos Enterprises administrative staff search, create, complete, delete, and track operational tasks.

Below is a set of instructions to help you navigate the Task Manager and use it effectively.

Instructions

On the Tasks page, you will find a list of all In Progress and Completed tasks. Completed tasks appear with a strikethrough.

Above the Task List, you have the option to Search for specific tasks using a key word or phrase.

Beside each task in the Task List are two options: Delete and Complete.

Below the Task List, you have the option to Create a New Task using the Create Task form.

Search Tasks

To Search for a task, use the Search box to enter a key word or phrase.

The key word or phrase can be the Task Name, Due Date, Priority Level, or Consultant.

Clicking the Search button will update the Task List to only display tasks that contain the key word or phrase you have entered.

Click the Clear Search button to clear your search and return to the default Task List.

Create a New Task

To Create a New Task, navigate to the Create Task form below the Task List.

In this form, you can give the New Task a Task Name (required), select the Due Date (required), set the Priority Level (Low, Medium, or High) (required), and assign a Consultant (optional).

Once you have filled in the required fields, click the Create Task button, and the task will be added to the list of In Progress and Completed tasks in the Task List.

You can Delete or Complete tasks in the Task List by selecting the appropriate control button.

Delete a Task

To Delete a Task, select the Delete button in the actions section at the right-hand side of the Task List table.

You will be prompted to confirm that you want to delete the task once with a message asking "Are you sure you want to delete this task?".

Selecting the Yes button will delete the task. The task will then be removed from the Task List.

Selecting No will take you back to the Task List.

Complete a Task

To Complete a Task, select the Complete button in the actions section at the right-hand side of the Task List table.

You will be prompted to confirm your action with a prompt asking "Are you sure you want to complete this task?"

Selecting the Yes button will complete the task. The task will remain in the Task List, but will appear with a strikethrough (e.g. Meet with client | 2026-10-08 | High).

Selecting No will take you back to the Task List.
