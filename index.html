Welcome to Task Manager

Task Manager is a responsive one page web application designed to help Gelos administrative staff create, search, complete, and track operational tasks.

Below is a set of instructions to help you navigate the Task Manager and use it effectively.



Instructions

On the Tasks page, you will find a list of all In Progress and Completed tasks. Completed tasks appear with a strikethrough.

Above the Task List, you have the option to Search for specific tasks using a key word or phrase.

Beside each task in the Task List are two options: Delete and Complete


Search for Task

To Search for a task, use the Search box to enter a key word or phrase.

The key word or phrase can be the Task Name, Due Date, Priority Level, or Consultant.

Clicking the Search button will update the Task List to only display tasks that contain the key word you have entered.

Click the Clear Search button to clear your search and return to the default Task List.


Add New Task

To Add a New Task, click the Add New Task button at the xxx of the page. This will bring up the Add New Task form.

In this form, you can give the New Task a name (required), select the due date (required), set the priority level (low, medium, or high) (required), and assign a consultant (optional).

Once you have filled in the required fields, click the Add Task button, and the task will be added to the list of In Progress and Completed tasks.

You can Delete or Complete tasks in the Task List by selecting the appropriate control button.


Delete a Task

Clicking the Delete button will delete the selected task.

You will be prompted to confirm that you want to delete the task once with a message asking "Are you sure you want to delete this task?".

Selecting the Yes button will delete the task. The task will then be removed from the Task List.

Selecting No will take you back to the Task List.


Complete a Task

To Complete a Task, select the Complete option from the controls at the right hand side of the page.

If you click this button, you will be asked to confirm your action with a prompt asking "Are you sure you want to complete these task?"

Clicking Yes will complete the selected task.

The task will remain in the Task List, but will appear with a strikethrough.

Selecting No will take you back to the Task List.
